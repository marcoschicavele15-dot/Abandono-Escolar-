# Educação Não Se Abandona — Website escolar

Website educativo sobre **Abandono Escolar e suas consequências**, desenvolvido em HTML, CSS e JavaScript puro.

## Conteúdo incluído
- Página inicial e apresentação do tema
- Introdução e enquadramento
- Objectivo geral, objectivos específicos e metodologia
- Causas do abandono escolar
- Consequências para aluno, família, comunidade e país
- Soluções e medidas de prevenção
- Recomendações para alunos, famílias, professores, escolas e comunidade
- Conclusão
- Identificação dos seis integrantes
- Referências bibliográficas com ligações institucionais

## Como abrir no computador ou telemóvel
1. Extraia o ficheiro ZIP.
2. Abra a pasta `abandono-escolar-site`.
3. Abra `index.html` num navegador (Chrome, Firefox, Edge).
4. É possível navegar pelo website sem servidor local. A ligação à Internet é necessária para carregar as fontes tipográficas externas.

## Como publicar gratuitamente no GitHub Pages
1. Entre em https://github.com/ e crie um repositório público, por exemplo `abandono-escolar`.
2. Carregue os ficheiros `index.html`, `styles.css`, `script.js` e este `README.md` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Seleccione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação. O GitHub apresentará o endereço público do website na secção Pages.

## Personalização académica
Na secção “Identificação do grupo”, preencha os campos “Disciplina”, “Escola”, “Turma / Classe” e “Docente” directamente no `index.html`, se necessário.

## Nota sobre investigação
O conteúdo é uma síntese educativa e não inventa entrevistas, questionários ou estatísticas. Se o grupo realizar trabalho de campo, pode acrescentar os resultados reais, respeitando a privacidade dos participantes. Consulte as fontes institucionais indicadas na página e registe a data de consulta no relatório final.
